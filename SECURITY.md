# Security Policy

## Supported versions

Security fixes are applied to the current default-branch version and, when applicable, the latest published release.

## Reporting a vulnerability

Please do **not** open a public issue for a suspected vulnerability involving sensitive data, credentials, extension permissions, local files, or user privacy.

Report it privately to **info@salt19.com** with:

- the affected repository and version or commit;
- clear reproduction steps;
- expected and observed behavior;
- potential impact;
- any relevant logs or screenshots with secrets and personal data removed.

Please do not include passwords, API keys, tokens, private records, resume contents, veteran records, or other sensitive user data.

SALT19 will acknowledge a reproducible report, assess severity, and coordinate a fix and disclosure when appropriate.
