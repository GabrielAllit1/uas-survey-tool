# Contributing

Thanks for your interest in improving this project.

## Before opening a pull request

1. Search existing issues and pull requests.
2. Open a focused issue for substantial behavior changes.
3. Keep changes small, reviewable, and within the repository's stated scope.
4. Do not add credentials, personal data, generated build artifacts, or unrelated dependencies.
5. Preserve privacy, permission, validation, and human-control boundaries documented in the README.

## Pull requests

Include:

- the problem being solved;
- the approach taken;
- testing or validation performed;
- screenshots for visible UI changes;
- any compatibility, privacy, or security implications.

By contributing, you agree that your contribution is provided under the repository's existing license.
